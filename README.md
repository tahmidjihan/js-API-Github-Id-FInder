# GitHub ID Finder

## Project Overview

🔍 **GitHub ID Finder** is a simple web tool built with **HTML**, **JavaScript**, and styled using **Tailwind CSS** along with **DaisyUI**. This tool allows users to quickly find GitHub user IDs by entering a GitHub username. The app utilizes **CDN links** for Tailwind CSS and DaisyUI for a lightweight setup.

## Technologies Used

- **HTML**: For structuring the web page.
- **JavaScript**: For handling the logic and fetching user data from GitHub's API.
- **Tailwind CSS**: For utility-first styling.
- **DaisyUI**: A plugin for **Tailwind CSS**, providing pre-built components for faster development.
- **CDN**: All libraries are loaded via CDN links for easy access and setup.
